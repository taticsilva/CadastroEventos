# Cadastro de Eventos

Projeto desenvolvido em **.NET MAUI** para a disciplina de Desenvolvimento de Sistemas.

## Sobre o projeto

O Cadastro de Eventos é um aplicativo que permite registrar informações básicas de um evento e visualizar um resumo com os dados cadastrados e o custo total.

## Funcionalidades

- Cadastro do nome do evento.
- Definição das datas de início e término.
- Informar o número de participantes.
- Cadastro do local do evento.
- Informar o custo por participante.
- Cálculo automático da duração do evento.
- Cálculo do custo total.
- Exibição de uma tela de resumo.

## Tecnologias utilizadas

- C#
- .NET MAUI
- XAML
- Visual Studio

## Exemplo de cadastro

- **Evento:** Palestra de Direito Digital, Inteligência Artificial e Cibersegurança
- **Data de início:** 23/11/2026
- **Data de término:** 25/11/2026
- **Participantes:** 2.000
- **Local:** Teatro Principal
- **Custo por participante:** R$ 100,00
- **Custo total:** R$ 200.000,00
